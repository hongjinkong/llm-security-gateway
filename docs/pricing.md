# 가격·계약 초안

> **초안 — 확정된 가격이 아니다.** 상용화 계획의 결정(PLAN.md 결정 표 9번)을 문서로 옮긴 것이다. 금액은 추정 구간이고 디자인 파트너 PoC가 끝난 뒤에 정한다. 계약 조항은 변호사 검토 대상이다. (D-132, 2026-11-10)

## 1. 원칙

- **코드는 전부 공개한다**(Apache-2.0). 돈을 내야 열리는 기능은 없다 — 무료로 쓰는 쪽과 계약한 쪽이 같은 코드·같은 이미지를 쓴다.
- 돈을 받는 것은 **배포 단위 연간 지원 계약**이다 — 설치와 PoC 지원, 문의 응답 시간, 컴플라이언스 문서.
- **좌석·토큰·요청 수로 과금하지 않는다.** 트래픽이 늘어도 값이 같다(자체 호스팅이라 우리가 셀 수도 없다).
- **자체 호스팅만** 한다. 우리는 고객의 트래픽·로그·키에 접근하지 않는다 — 지원도 고객이 보여 주는 화면과 [감사 로그](operations.md#로그)(원문이 없다)로 한다.

'배포 단위'는 한 조직의 한 운영 환경(과 거기에 딸린 시험 환경)이다. 파드 수·요청 수·사용자 수와 무관하다.

## 2. 구성(초안)

| | 커뮤니티 | 지원 계약 |
|---|---|---|
| 값 | 무료 | 배포 단위 연 600만 ~ 2,000만 원(추정 — 응답 시간·배포 수에 따라) |
| 코드·이미지·문서 | 같다 | 같다 |
| 설치 | [운영 문서](operations.md) | 하루 설치 동행(원격) |
| PoC | 스스로 | 2주 관측 리포트를 함께 읽는다 — `scripts/poc_report.py`(샘플의 탐지·오탐 후보), `scripts/poc_gate.py`(감사 로그 판정) |
| 문의 | GitHub 이슈(응답 보장 없음) | 영업일 기준 1일 안에 첫 응답(초안) |
| 보안 취약점 | [SECURITY.md](../SECURITY.md) 절차 | 같은 절차 + 수정 릴리스를 먼저 알린다 |
| 업그레이드 | [변경 기록](../CHANGELOG.md)·서명된 릴리스 이미지 | 대체값 키·탐지 규칙이 바뀌는 버전의 영향 안내, 업그레이드 동행 연 2회 |
| 컴플라이언스 문서 | [보안 백서](security-whitepaper.md)·[법적 위치 메모](legal-position.md)(변호사 검토 전 초안) | 고객 양식의 보안 점검표 답변, 데이터 흐름도 |
| 오탐 예외 | 스스로 | PoC에서 나온 오탐 후보를 함께 분류한다 |

## 3. 디자인 파트너(첫 1곳) 조건(초안)

- 첫 해 지원 계약을 받지 않는다(또는 크게 깎는다 — 정할 것).
- 대신: 2주 관측의 **집계**(종류별 건수·오탐 후보의 값 모양 — 원문은 받지 않는다)를 함께 보고, 격주 30분 피드백, 사례 인용 동의(회사 이름 공개는 선택).
- 순서: 하루 설치 → 2주 `observe`(가리지 않고 기록만) → 리포트 → `mask` 전환 → 2주 → 아래 기준 판정.

## 4. v1.0 기준

`mask`로 돈 연속 14일 이상의 [감사 로그](operations.md#로그)에서(D-132에 미리 적은 정의):

| 기준 | 정의 |
|---|---|
| 의심 잔여 < 0.1% | 가짜 값을 발급한 요청 가운데 복원 실패 신호(`pii_suspect` > 0)가 있는 요청의 비율 |
| 실패 < 0.1% | 전체 요청 가운데 게이트웨이 몫 실패(5xx와 스트림 도중 실패)의 비율 — 공급자 장애(상류 5xx·연결 실패)와 클라이언트가 끊은 요청은 따로 센다 |

```bash
python3 scripts/poc_gate.py audit.jsonl
```

관측(`observe`) 구간은 도구가 스스로 뺀다 — 가림이 처음 나온 줄부터가 mask 구간이고, 그 안에 빈 날이 있으면 기간으로 치지 않는다. 분모가 1,000건이 안 되면 판정하지 않는다(기간을 늘린다).

## 5. 계약에 넣을 것(변호사 검토 대상)

- **범위**: 소프트웨어는 Apache-2.0 그대로(무보증). 계약의 대상은 지원 용역이다.
- **보증하지 않는 것**: 탐지율·오탐률(측정값을 준다 — 백서 9절의 한계), 공급자의 처리.
- **개인정보**: 고객이 개인정보처리자다. 우리는 고객 트래픽을 받지 않는다 — 수탁자가 되지 않는 구조를 유지한다([법적 위치 메모](legal-position.md)와 맞춘다).
- **응답 시간**: 첫 응답 시간만 약속한다. 가용성은 약속하지 않는다(고객 인프라에서 돈다).
- 비밀유지, 기간(1년)·갱신·해지, 책임 한도(연 계약 금액).

## 6. 정해야 할 것

- 금액 구간과 무엇에 따라 달라지는지(응답 시간·배포 수).
- 디자인 파트너의 첫 해 조건(무상인지 할인인지).
- 계약 주체(사업자 형태)와 세금계산서.
